## 实际修改

- `frontend/src/app/App.tsx`：统一导航、品牌、面包屑、双语选择、创建入口、手机导航与 Escape 关闭；增加 `?page=` 页面定位、刷新恢复和浏览器返回。所有既有业务入口保留。
- `frontend/src/app/Overview.tsx`：适配产品介绍稿，提供真实页面跳转；未复制样例回答、人物或“零幻觉”保证。
- `frontend/src/components/ui/metrics.tsx`：共用指标组件，读取实际列表数据；加载时显示占位，受筛选影响的计数明确标为“当前匹配”。
- `frontend/src/styles.css`：替换旧绿色/衬线视觉体系，建立统一变量、卡片、表单、按钮、状态、引用、布局与断点；保留原生语义控件与清晰键盘焦点；减少动态效果偏好可关闭动画。
- `KnowledgePanel`：真实文档指标、名称/状态筛选、列表布局和双语文件选择区域，原 API 与所有操作保持连接。
- `ChatPanel`：横向会话切换、保留 SSE/停止/失败重试、PDF 上下文、消息原文和引用；侧栏显示所选回答或最近一次带来源回答，原件链接不变。修正原有将 CSS 类名传入翻译函数的写法。
- `MeetingPanel`：上传和已存会议索引与详情双栏，保留日期/时区、处理进度、人物、决策、风险、任务、邮件、原始行和审计。上传控件使用明确的双语名称。
- `MemoryPanel`：真实计数、版本卡片时间线、现有筛选/历史/纠正/撤销/别名与身份合并入口。原始证据不改写。
- `ActionsPanel`：任务与邮件审阅双栏、真实计数、紧凑表单；保存草稿与发送严格分离，仍按原有版本与幂等键批准；明确任务状态选择器的无障碍名称。
- `PresentationPanel`：可折叠生成配置、真实搜索来源/检索时间、已存文稿选择器、状态与进度、大纲跳转、完整 PDF.js 预览及下载。选中文稿后收起长配置表单；未知/失败文稿不出现可下载成品。
- `frontend/src/locales/zh.json`：新增界面文案中文映射。沿用现有 `i18n.ts` 和 `memora.language` 持久化；请求语言及后台任务提交语言契约未变。现存消息、会议、邮件、记忆和文稿内容继续保持原文。

## 设计差异与保留问题

1. 设计稿包含企业组织、配额、虚构 KPI、Qdrant 集群、LDAP/声纹、置信度及“100%/零幻觉”等未获现有系统支持的展示。本地应用不显示这些数据或保证，改用真实列表计数、来源和状态。
2. 设计稿中的 OCR、分块坐标检视、审计 ZIP 导出、拖拽重排/单页 AI 重写、富文本 AI 润色、通知和全局搜索均没有对应现有服务。本轮未新增业务能力，也没有留下虚假按钮。上传采用直接可访问的文件选择区，不复制静态弹窗；审计继续使用真实会议审计记录。
3. Inter / JetBrains Mono 按 DESIGN 的字体栈声明；设计资料没有字体文件，不引入运行时 Google Fonts/CDN 依赖。未安装指定字体时使用系统无衬线/CJK 与等宽回退，因此不宣称像素级字体一致。原生日期弹层遵循浏览器/操作系统区域设置，输入字段使用 ISO/明确 UTC 标注，展示日期沿用 Intl 与原时区。
4. 产品介绍稿适配为工作区概览，没有复制静态“实时”问答演示、企业版权/法务承诺或虚构管理员头像；真实聊天与证据位于聊天页。
5. PPT 大纲使用实际结构化标题/摘要卡片，不是重绘的假截图；文稿实体预览来自对应 PDF。没有复刻设计稿固定的绿色认证印章或修改现存成品配色。
6. 本次不改变先前真实六页内容验收的失败状态，也不重试外部模型。具体引文失败仍见 `ppt-content-acceptance.md`。浏览器下载回归验证事件和链接，独立 UI 下载 fixture 不代表重新验收 PPTX 文件结构或真实模型内容。

## 可直接操作的检查步骤

1. 打开 http://localhost:5173 ，默认简体中文；顶部切换 English，刷新确认偏好保留。
2. 概览检查主视觉和能力入口；聊天切换已存会话，检查引用及右侧证据面板。
3. 知识库检查现有文件或空状态，按需上传自己的 PDF；上传/索引可能调用已配置 Embedding，请由用户明确操作。
4. 会议选择已存记录，查看摘要、人物、原始行、风险、任务、邮件和审计；切换“记忆时间线”后筛选实体/历史。无需重新提取即可查看已有结果。
5. 任务与行动检查表单与邮件草稿。仅审阅不会发送；发送仍需明确批准，当前保持本地 Mailpit。
6. 演示文稿选择已有文稿，查看大纲、六页 PDF 和下载入口；失败任务显示真实失败。查看旧文件不代表其内容验收通过。创建新文稿或搜索会使用已配置服务，本轮未自动执行。
7. 设置查看基础服务健康。缩窄浏览器或使用手机尺寸，检查菜单、表单和横向大纲。
